# BrightStart Attendance Dashboard

A responsive, beginner-friendly attendance dashboard designed for an early childhood development (ECD) centre.

## Why I built this

I have more than eight years of experience working in ECD settings. I wanted to practise front-end development by designing a simple tool for a real admin task: tracking daily attendance clearly and respectfully.

## Features

- Responsive layout for mobile and desktop
- - Attendance summary cards
  - - Click-to-change Present / Absent status
    - - Search children by name
      - - Light and dark theme toggle
        - - Sample data only — no real child information
         
          - ## Built with
         
          - - HTML
            - - CSS
              - - JavaScript
               
                - ## What I learned
               
                - This project helped me practise semantic HTML, CSS layouts, responsive design, JavaScript events, DOM updates, filtering and theme switching.
